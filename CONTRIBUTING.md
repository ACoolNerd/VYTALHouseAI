# Contributing

1. Create a branch for each account list, financial-model update, sales asset, or compliance revision.
2. Cite public sources in account and contact records.
3. Do not add confidential, medical, school, clearance, or protected government information.
4. Label all financial assumptions.
5. Require management approval before changing public pricing.
6. Run `python scripts/validate_data.py` before opening a pull request.
